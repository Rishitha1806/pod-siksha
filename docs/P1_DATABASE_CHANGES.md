# Pod-Siksha: Phase P1 Database Changes & Migration Reference

## Overview
Phase P1 introduces persistent state management for:
1. **Interactive Oral Quizzes** (`quiz_sessions`)
2. **Cognitive Oral Questions** (`quiz_questions`)
3. **Student Spoken Answers & Evaluations** (`quiz_answers`)
4. **Concept Intelligence & Friction Tracking** (`concept_events`)

All schema alterations are additive and backwards-compatible with the Phase P0 baseline schema (`sessions`, `turns`, `doubts`).

---

## 1. Complete DDL for P1 Tables

### Table: `quiz_sessions`
Tracks an oral quiz instance associated with a parent podcast session.
```sql
CREATE TABLE IF NOT EXISTS quiz_sessions (
    id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL,
    total_questions INTEGER DEFAULT 4,
    completed_questions INTEGER DEFAULT 0,
    total_score INTEGER DEFAULT 0,
    max_score INTEGER DEFAULT 400,
    status TEXT DEFAULT 'in_progress', -- 'in_progress', 'completed'
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    completed_at TIMESTAMP,
    FOREIGN KEY(session_id) REFERENCES sessions(id) ON DELETE CASCADE
);
```

### Table: `quiz_questions`
Stores the 4 cognitive questions generated by Google Gemini across Blooms taxonomy levels.
```sql
CREATE TABLE IF NOT EXISTS quiz_questions (
    id TEXT PRIMARY KEY,
    quiz_id TEXT NOT NULL,
    question_index INTEGER NOT NULL, -- 1, 2, 3, 4
    cognitive_type TEXT NOT NULL,    -- 'Basic', 'Conceptual', 'Application', 'Reasoning'
    concept TEXT NOT NULL,
    question_text TEXT NOT NULL,
    ideal_answer TEXT NOT NULL,
    audio_path TEXT,                -- cached Gnani Timbre audio path or stream ref
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY(quiz_id) REFERENCES quiz_sessions(id) ON DELETE CASCADE
);
```

### Table: `quiz_answers`
Stores student spoken responses, Prisma STT transcripts, and Gemini 3-category evaluations.
```sql
CREATE TABLE IF NOT EXISTS quiz_answers (
    id TEXT PRIMARY KEY,
    quiz_id TEXT NOT NULL,
    question_id TEXT NOT NULL,
    student_transcript TEXT NOT NULL,
    evaluation TEXT NOT NULL,       -- 'correct', 'partially_correct', 'incorrect'
    score INTEGER NOT NULL,          -- 100, 50, 0
    feedback_text TEXT NOT NULL,
    feedback_audio_path TEXT,
    answered_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY(quiz_id) REFERENCES quiz_sessions(id) ON DELETE CASCADE,
    FOREIGN KEY(question_id) REFERENCES quiz_questions(id) ON DELETE CASCADE
);
```

### Table: `concept_events`
Canonical concept intelligence log capturing doubts, ladder escalations, and quiz outcomes for teacher analytics.
```sql
CREATE TABLE IF NOT EXISTS concept_events (
    id TEXT PRIMARY KEY,
    session_id TEXT NOT NULL,
    concept_normalized TEXT NOT NULL,
    raw_query TEXT,
    event_type TEXT NOT NULL,       -- 'doubt', 'quiz_answer', 'hint_escalation'
    score INTEGER,                  -- 0, 50, 100 for quiz answers; NULL for doubts
    hint_level INTEGER,             -- 1, 2, 3 for doubts; NULL for quiz answers
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY(session_id) REFERENCES sessions(id) ON DELETE CASCADE
);
```

## 2. Indexes

```sql
CREATE INDEX IF NOT EXISTS idx_quiz_questions_quiz ON quiz_questions(quiz_id);
CREATE INDEX IF NOT EXISTS idx_quiz_answers_quiz ON quiz_answers(quiz_id);
CREATE INDEX IF NOT EXISTS idx_concept_events_session ON concept_events(session_id);
CREATE INDEX IF NOT EXISTS idx_concept_events_concept ON concept_events(concept_normalized);
```

## 3. Concept Normalization Rule Engine

Concept names extracted during doubt processing or quiz questions are mapped to canonical ontology roots:
- `water splitting`, `photolysis of water`, `water oxidation` $\to$ `Water Photolysis`
- `light reaction`, `light-dependent reaction`, `thylakoid reactions` $\to$ `Light Reactions`
- `dark reaction`, `calvin cycle`, `carbon fixation`, `light-independent` $\to$ `Dark Reactions (Calvin Cycle)`
- `chloroplast`, `chlorophyll`, `grana`, `stroma`, `thylakoid` $\to$ `Chloroplast Structure`
- `photosynthesis equation`, `overall reaction`, `reactants and products` $\to$ `Photosynthesis Overview`
- `stomata`, `guard cells`, `gas exchange`, `transpiration` $\to$ `Stomatal Regulation`
- `atp synthase`, `photophosphorylation`, `chemiosmosis` $\to$ `ATP Synthesis`
- `electron transport chain`, `etc`, `ps i`, `ps ii`, `cytochrome` $\to$ `Electron Transport System`

This ensures that the Teacher Observatory radar aggregates disparate student phrasing into unified pedagogical clusters.
